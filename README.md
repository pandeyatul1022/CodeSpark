# 🚀 CodeSpark

**CodeSpark** is a modern, interactive e-learning platform designed to make coding education accessible, engaging, and fun. Built with a sleek UI and powerful features, CodeSpark helps students learn programming through courses, quizzes, and a hands-on coding lab.

## ✨ Features

- 🏠 **Beautiful Landing Page** — Modern hero section with animated carousels and smooth scroll effects
- 📚 **Courses** — Browse and explore programming courses
- 🧪 **Coding Lab** — Practice coding in a hands-on environment
- 📝 **Quizzes** — Test your knowledge with interactive quizzes
- 🔐 **Authentication** — Login & Registration pages with form validation
- 📧 **Contact Us** — Reach out via an elegant contact form
- ℹ️ **About Us** — Learn about the CodeSpark mission
- 🌙 **Dark / Light Mode** — Seamless theme toggling for comfortable browsing
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop
- ✨ **Smooth Animations** — AOS (Animate on Scroll) powered transitions
